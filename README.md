# 12A_2026_Klassen

Erstellt eine Klasse für ein Objekt aus einem Escape Room. 
Das Objekt soll am Ende des Namens eure Katalognr. haben. 
Das Objekt beinhaltet 3 Daten, 2 Konstruktoren und 2 Methoden. 
Die Methoden sollen Aufgaben für den Escape Room für das betreffende Objekt lösen.

1. Baut einen neuen Branch genannt <Name>-level-1
2. Verändert Program.cs und fügt eure Klasse hinzu.
3. Commitet die Änderungen und pusht den Branch auf GitHub.
4. Löscht den alten Branch mit eurem Namen.
5. Erstellt einen Pull Request auf GitHub.
